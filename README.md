# Homebrew tap for kc

[kc](https://github.com/stokaro/kc) is a two-panel Kubernetes TUI in the style of Midnight Commander.

```bash
brew install --cask stokaro/kc/kc
```

The cask in `Casks/kc.rb` is written by the kc release workflow (GoReleaser) for each release; do not edit it by hand. Report problems in [stokaro/kc](https://github.com/stokaro/kc/issues).
